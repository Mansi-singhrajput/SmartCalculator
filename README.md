# Smart Calculator

A modern web-based Smart Calculator built using HTML, CSS, and JavaScript.

## Features
- Basic arithmetic operations (+, -, ×, ÷)
- Square (x²)
- Square Root (√)
- Percentage (%)
- Power (xʸ)
- Trigonometric functions (sin, cos, tan)
- Logarithm
- Pi (π)
- Random Number
- Copy Result
- Dark Mode
- Calculation History
- Live Clock

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Files
- index.html
- Calc.css
- cals.js
